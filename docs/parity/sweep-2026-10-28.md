# 本家と Heavy の全画面の見比べ（2026-10-28）

本家は jp.linkaigc.com（www.lightchainai.com は宣伝サイト）を Companion でログインして開いた。Heavy は heavychain.app（heavy-chain.zeabur.app は 404 で使えなくなっている）。
本家の画面の一覧は、本家の JS の path から抜き出して 10/7 の route-ledger と突き合わせた。新しいのはトップの「事例共有」の詳細（/designProduction/case・/marketing/case）だけ。

## 本家で使えない（このアカウントでは「権限がありません」）のでスキップした画面

生地イメージ（/tools/fabric）、AIフィッティング（/model）。10/7 に使えた機能にも鍵がかかっている。
線画の実写化・平絵生成・ベクター通常版・平絵ベクター・画像修正・各エディタは 10/7 の時点で鍵つき。

## 同じだった画面

トップ（新しい形にすでに合っていた）、デザインワークスペース（プロジェクト・対話）、マーケティングワークスペース、AIグラフィックデザインの配置、ライブラリーの形、ベクター化プロ版の形。

## わざと残した違い（過去の QA で決めたもの）

- ツール画面の「この機能はまもなく終了します」の赤い帯を出さない（#77、10/9）
- ベクター化のタブ名を短くする（#98、10/10）
- AIグラフィックデザインの右の欄の案内文（#97、10/9）

## 残っている違い

- 本家はツールで上げた画像（服・プリント）がすべてライブラリーの「履歴アップロード」に入る。Heavy は入らない（2枚目以降のプリントは画面と下書きにだけある）。
- 本家の事例には日付と手順ごとの画像がある。Heavy の事例データに無いので出していない。
- プリント編集の「選択範囲にオブジェクトを追加 ▾」「ワンクリックでトリミング」、ステップ2 の一番上の道具（◐）は本家で中身を確かめきれていない。
- 本家のプリント編集では、白い背景のプリントも背景を消さずにそのまま使っている（Heavy も同じ動き）。
